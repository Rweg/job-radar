# Rwego Job Radar

Live site: https://rweg.github.io/job-radar/

This is the sanitized GitHub Pages deployment of the private [Rweg/job-applications](https://github.com/Rweg/job-applications) workspace. It contains public job-opportunity metadata and preparation guidance only.

The site covers Rwanda, selected African opportunities, worldwide remote roles, Canada, the United States, and Europe. Each record separates technical fit from work authorization, sponsorship, relocation, salary, and deadline facts. Every job includes a source link, an application link, evidence to show, gaps to close, interview themes, and next actions.

No passports, transcripts, references, private contact details, employer-confidential material, internal URLs, customer data, source code, or application essays are published here.

The deployment is refreshed from public employer sources through GitHub Actions. Rolling roles are labeled as rolling; unknown facts remain marked as unknown rather than guessed.
